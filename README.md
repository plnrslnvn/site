# CMS в электронной коммерции

Учебный веб-проект об использовании CMS в электронной коммерции. Сайт знакомит с тремя популярными решениями для интернет-магазинов — WooCommerce, Shopify и Magento, а также содержит сравнение платформ, материалы по безопасности и SEO, скорость загрузки и практические кейсы.

Проект выполнен как статический многостраничный сайт без серверной части и системы сборки.

## Возможности

- Главная страница с обзором CMS для e-commerce
- Отдельные страницы о WooCommerce, Shopify и Magento
- Сравнительная таблица CMS
- Разделы о безопасности и SEO/скорости загрузки
- Практические кейсы использования платформ
- Адаптивное меню с мобильным режимом
- Боковая навигация по содержимому страниц
- Оформление в стиле ретро/8-bit с использованием NES.css
- Корректная работа сайта как статического проекта, в том числе через GitHub Pages

## Используемые технологии

| Технология   | Назначение                                           |
| ------------ | ---------------------------------------------------- |
| HTML5        | Разметка страниц сайта                               |
| CSS3         | Кастомные стили, сетка, адаптивность и оформление    |
| JavaScript   | Интерактивное мобильное меню                         |
| NES.css      | CSS-фреймворк для визуального стиля в духе ретро-игр |
| Google Fonts | Шрифт Press Start 2P                                 |
| GitHub Pages | Публикация статического сайта                        |

NES.css и шрифт подключаются напрямую через CDN, поэтому отдельная установка npm-пакетов для запуска проекта не требуется.

## Запуск проекта

### Вариант 1 — открыть напрямую

Для быстрого просмотра можно открыть файл `index.html` в браузере.

```bash
# просто откройте файл в браузере двойным кликом
index.html
```

Для большинства страниц этого достаточно, так как проект не использует серверную часть или сборщик.

### Вариант 2 — через VS Code

1. Откройте папку проекта в Visual Studio Code.
2. Установите расширение **Live Server**.
3. Откройте `index.html`.
4. Нажмите **Go Live** — сайт откроется в браузере.

## Публикация на GitHub Pages

Проект не требует сборки, поэтому его удобно размещать на GitHub Pages.

1. Создайте репозиторий на GitHub.
2. Загрузите файлы проекта в репозиторий.
3. Перейдите в **Settings → Pages**.
4. В разделе публикации выберите ветку (например, `main`) и папку `/root`.
5. Сохраните настройки.

После публикации GitHub Pages предоставит адрес работающего сайта.

> **Важно:** если сайт использует изображения из папки `assets/`, эта папка также должна быть загружена в репозиторий с сохранением исходной структуры каталогов.

## JavaScript

Файл `jsmain.js` отвечает за мобильную навигацию:

- открытие и закрытие меню по кнопке;
- закрытие меню после выбора пункта;
- закрытие меню при клике за его пределами.

Подключение в HTML:

```html
<script src="jsmain.js"></script>
```

## Стилизация

Основная библиотека интерфейса — **NES.css**. Дополнительное оформление находится в `csscustom.css`.

Пользовательские стили отвечают за:

- структуру страницы с боковой панелью;
- адаптивную сетку;
- оформление карточек;
- навигацию;
- цвета и типографику;
- мобильное меню;
- изображения и таблицы.

## Внешние зависимости

Проект использует внешние ресурсы:

- **NES.css** — подключается через `unpkg.com`;
- **Google Fonts** — шрифт Press Start 2P.

Для работы этих ресурсов при загрузке страницы требуется доступ к интернету. Сам HTML/CSS/JavaScript проекта при этом не требует установки пакетов.
